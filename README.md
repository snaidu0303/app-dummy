# Aurora - React TypeScript Landing Page

A modern, responsive landing page built with React 18, TypeScript, and Vite.

## Features

- **Vite + React 18 + TypeScript**: Lightning-fast build times, strict typing, and instant hot-module replacement.
- **Modern UI & Responsive Design**: Custom glassmorphism styling, dark mode theme, glow gradients, and mobile-friendly responsive layout.
- **Interactive Components**:
  - Live interactive terminal / architecture showcase tabs (Terminal, Config, Metrics)
  - Interactive billing period toggle (Monthly vs Annual with 20% discount badge)
  - Interactive FAQ accordion
  - CLI quick-copy button with copy feedback state
  - Mobile hamburger drawer navigation
  - Newsletter / Early access subscription form
- **Lucide Icons**: Crisp, modern SVG icons throughout the interface.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
